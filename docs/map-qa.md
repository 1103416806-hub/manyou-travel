# 交互地图与用餐区域验收

日期：2026-09-13。范围仅为独立的慢游旅行助手项目。

## 本轮实现

- 行程与真实 OpenStreetMap 底图并排，日期切换同步标记、详情和路线。
- 编号标记可点击，弹窗显示地点、时间及该活动关联的来源；完整资料保留原有查看入口。地图选择与行程高亮同步。
- 方向箭头连接显示的行程节点，表达访问先后；不是道路导航或交通耗时计算。
- 杭州演示午餐显示暖黄色编号、餐饮图标和虚线区域，补齐 ①→②→③→④。区域是人工选区建议，不是餐馆位置或检索结果。
- 用餐区域与景点过近时，偏移屏幕标签并用细线连回区域中心；不修改参考坐标。
- 演示地点采用可追溯 WGS84 目录，已有本地演示数据兼容迁移；普通未知位置仍显示待定位。

## 当前边界

底图需要网络；提供加载、局部失败与重试状态。未在浏览器强制断网模拟所有网络错误。

小红书、抖音尚未配置实际检索服务，演示来源始终标注为示例。OpenStreetMap 区域出处只支持位置参考，不支持餐馆营业、口碑、票价或出行当天可用性。已有真实来源记录时，地图按活动 source_ids 显示对应平台、标题、摘要与原文链接。

五个用餐区域使用前端独立展示数据，不写入活动的精确坐标字段，也不会把活动标记为已验证。第 4、5 天的区域资料已配置并通过类型构建检查，本轮浏览器未逐天验收这两天。
