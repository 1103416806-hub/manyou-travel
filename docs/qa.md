日期：2026-09-12。环境：本机 Windows、Python 服务 127.0.0.1:8766、Codex 内置浏览器。以下是本次实际执行的检查，不代表真实用户研究。

## 自动检查

- 前端 `npm run build`：TypeScript 与 Vite 构建通过，使用新项目独立安装的依赖；没有依赖原个人网站的目录链接。
- `python -m unittest discover -s evals -p 'test_*.py' -v`：27 项测试通过，0 失败（包含支持天数与节奏组合的子场景）。
- 覆盖日期、人数、预算超支、时间冲突、来源 ID、示例标签、危险导入 URL、窗口外/部分天气、缺少配置的错误和跨站请求拒绝。
- `evals/cases.json` 是另一个 20 条设计期场景目录，仍保留 not_run；不能把这 27 项回归结果直接等同于 20 条场景全部通过。

## 视觉检查

桌面按浏览器默认约 1266×712，手机按 390×844 视口检查；手机内容宽度与 scrollWidth 均为 375（扣除滚动条），未出现整页横向溢出。日期标签允许局部横向滚动。

1. 暖白底、深绿侧栏、少量珊瑚色使用一致；正文与图标层次可辨。
2. 标题、日标签、时间线具有稳定层级；示例标识在主横幅可见。
3. 桌面正文与右侧路线/天气并列；手机顺序堆叠，导航折叠。
4. 手机表单可滚动，日期、人数、节奏、提交按钮可操作，没有弹窗越界。
5. 西湖配图裁切正常，标注为意境配图；路线图明确为示意、非导航。

本轮据实际检查修正了未知费用误写免费、来源示例链接文案、日期范围不一致，以及更新天气后遗留的旧提示。

## 未验证与限制

- 没有真实模型与小红书/抖音授权条件，未跑付费生成或登录平台检索的端到端评估。
- 结构通过不代表景点开放、预约、票价、地图交通或可达性真实有效。
- 未执行真实打印机任务；按钮限定为打印当天，完整旅行通过文本导出。
- 浏览器直接下载未捕获到完成事件；为此增加导出全文预览与复制入口，避免只依赖下载行为。
- 初版不包含账户、云同步、实时导航、票务库存和视频转写。

后端的补充检查与具体未测项见 `backend-qa.md`。产品指标与未来真实数据评估方案见 `product-strategy.md`。
